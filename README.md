# The Internet in One Word — entry

A single word for the whole internet, written by `main.py` to `/output/entry.txt`. The word: "Procrastopia" — the place everyone actually lives online, where every visit starts as a five-minute break and ends three hours later. It fits the whole internet rather than one app, reads in one beat, and is not the first obvious word anyone reaches for.
